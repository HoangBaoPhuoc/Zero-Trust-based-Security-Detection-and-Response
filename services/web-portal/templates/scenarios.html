⚡ Đây là nơi chứng minh Zero Trust hoạt động thật
Mỗi thẻ bên dưới mô phỏng 1 kỹ thuật tấn công thật (ánh xạ MITRE ATT&CK), nhắm đúng vào 1 lớp phòng thủ cụ thể trong kiến trúc. Nhấn "Chạy kịch bản" để gửi request thật tới hệ thống — kết quả trả về trực tiếp từ Keycloak / OPA / SPIRE / Fraud Detection, không phải dữ liệu giả lập.
🛡 Painpoint: Danh tính & quyền truy cập giả mạo — mong đợi: BỊ CHẶN
Kiến trúc truyền thống thường tin tưởng bất kỳ ai đã ở "bên trong mạng nội bộ". 4 kịch bản dưới đây giả lập kẻ tấn công đã có quyền truy cập mạng nhưng KHÔNG có danh tính hợp lệ — Zero Trust không tin ai theo mặc định, kể cả khi đã ở trong VPC.
Không có JWT T1078
🔑 Lớp: Keycloak / API Gateway
Gọi POST /payments không có Authorization header. API Gateway chặn ngay — Envoy log ghi lại trong Loki.
Kỳ vọng: HTTP 401/403 — missing bearer token
JWT giả mạo (ký sai key) T1078.001
🔑 Lớp: Keycloak JWKS verify
Gửi JWT ký bằng key không phải Keycloak. API Gateway verify JWKS — signature không khớp → reject.
Kỳ vọng: HTTP 401 – invalid_signature
Lateral Movement — SVID giả T1021
🔒 Lớp: SPIRE mTLS + OPA
Gọi endpoint nội bộ với SVID giả spiffe://evil.corp/attacker → bị chặn. OPA log ghi lại — kích hoạt Grafana alert "Lateral Movement".
Kỳ vọng: HTTP 403/404 — internal path blocked
Fraud Gate Block T1078.002
💰 Lớp: Fraud Detection + OPA
Chuyển 500,000,000 ₫ qua kênh tor. Fraud score=75 (500M: +55, tor: +15) → OPA từ chối → Grafana alert "Fraud Gate Bypass".
Kỳ vọng: HTTP 403 – fraud_block
⏱ Painpoint: Lạm dụng tốc độ giao dịch — velocity & rate limit
Một request đơn lẻ hợp lệ có thể vô hại — nhưng 100 request hợp lệ liên tiếp trong 1 phút thì không. Đây là kiểu tấn công mà kiểm tra danh tính đơn thuần không bắt được, cần theo dõi hành vi theo thời gian.
High Velocity (10 tx/15s) T1499
💰 Lớp: Redis velocity counter
Gửi 10 giao dịch nhỏ liên tiếp. Redis đếm velocity trong 60s — fraud score tăng dần theo từng batch.
Kỳ vọng: score tăng dần, giao dịch cuối score > 30
Rate Limit (65 req/min) T1498
🔑 Lớp: API Gateway rate limiter
Gửi 65 GET /health liên tiếp đến API Gateway. Giới hạn 60 req/min/IP — vượt ngưỡng bị block.
Kỳ vọng: req 61+ → HTTP 429 Too Many Requests
📊 Painpoint: Phát hiện & cảnh báo — detection pipeline (PLG stack)
Chặn được request là chưa đủ — đội vận hành cần BIẾT ngay khi có bất thường. Các kịch bản dưới đây bơm log tấn công thật vào Loki để kiểm chứng Grafana alert rule có bắt đúng và bắt kịp thời gian hay không.
Brute Force Login (inject) T1110.001
📊 Lớp: Grafana Alert Rule
Inject 20 log response_code=401 vào Loki stream {job="envoy-access"}. Grafana alert rule đánh giá mỗi 1 phút → fire ngay.
Kỳ vọng: Grafana alert "Brute Force Login" → Firing trong ~1 phút
